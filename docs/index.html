Cinewright is an open-source skill for Codex, Claude Code and friends. Every frame is code, every sound is synthesised — no stock footage, no video model, no cloud. Persian & RTL are first-class.سینه‌رایت یک اسکیل متن‌باز برای Codex، Claude Code و هم‌قطارانشان است. هر فریم کد است و هر صدا با کد ساخته می‌شود — بدون ویدیوی استوک، بدون مدل ویدیوساز، بدون ابر. فارسی و راست‌به‌چپ درجه‌یک.

Don't take our word for itحرف ما را باور نکنید

  
Same prompt. With and without the skill. Measured.پرامپت یکسان. با و بدون اسکیل. اندازه‌گیری‌شده.

  
The repository ships a benchmark that hands a coding agent (Codex by default) the same task in a clean folder under different conditions, then measures every film. Numbers below come straight from the committed results — no hand-typing.ریپو یک بنچمارک دارد که همان تسک را در پوشهٔ تمیز و شرایط مختلف به ایجنت (پیش‌فرض Codex) می‌دهد و هر فیلم را می‌سنجد. اعداد زیر مستقیم از نتایج ثبت‌شده می‌آید — بدون تایپ دستی.

  

  

  
quiet % = share of the film where almost nothing changes (the slideshow metric — lower is better). It measures motion and sound hygiene, not beauty; one run per cell is an anecdote. Full report & method · run it yourself — and tell us if it contradicts us.ساکن % = سهمی از فیلم که تقریباً هیچ چیز در آن تغییر نمی‌کند (معیار اسلایدشو — کمتر بهتر است). سلامت حرکت و صدا را می‌سنجد نه زیبایی؛ یک اجرا برای هر خانه فقط یک حکایت است. گزارش کامل · خودتان اجرا کنید — و اگر خلافش درآمد بگویید.
