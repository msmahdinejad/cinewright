Your coding agent can now direct films.ایجنت کدنویستان حالا می‌تواند فیلم بسازد.

Cinewright is an open-source skill for Codex, Claude Code and friends. Every frame is code, every sound is synthesised — no stock footage, no video model, no cloud. Same prompt, same agent: the difference is the skill.سینه‌رایت یک اسکیل متن‌باز برای Codex، Claude Code و هم‌قطارانشان است. هر فریم کد است و هر صدا با کد ساخته می‌شود — بدون ویدیوی استوک، بدون مدل ویدیوساز، بدون ابر. پرامپت یکسان، ایجنت یکسان: تفاوت فقط اسکیل است. فارسی و راست‌به‌چپ هم درجه‌یک پشتیبانی می‌شود.

The proofاثبات

Same prompt. Same agent. With and without Cinewright.پرامپت یکسان. ایجنت یکسان. با سینه‌رایت و بدون آن.

Each agent got the identical request in a clean folder; the only difference is the skill. Codex ran unattended at xhigh reasoning (gpt-6-astra, and gpt-6.1-sol on the showreel). Pick a prompt below — everyday motion graphics first. Every agent is compared with itself — never with another agent. Press play: the sound is part of the result.هر ایجنت همین درخواست را در یک پوشهٔ تمیز گرفت؛ تنها تفاوت، اسکیل است. Codex بدون نظارت و با ریزنینگ xhigh اجرا شد (gpt-6-astra، و روی شوریل gpt-6.1-sol). یکی از پرامپت‌های زیر را انتخاب کنید — موشن‌گرافی‌های روزمره اول. هر ایجنت فقط با خودش مقایسه می‌شود، نه با ایجنت دیگر. پلی بزنید: صدا هم بخشی از نتیجه است.

01 — ENGINE

Real motion, not slidesحرکت واقعی، نه اسلاید

A motion-graphics kit and a GPU toolkit written from scratch, deterministic down to the pixel.یک کیت موشن‌گرافی و جعبه‌ابزار GPU که از صفر نوشته شده و تا سطح پیکسل قطعی است.

  • Cut into one-idea shots, not slides: eleven scene types, seven themes, 50 self-drawing icons, counters and chartsبریده به شات‌های تک‌ایده‌ای، نه اسلاید: یازده نوع صحنه، هفت تم، ۵۰ آیکونِ خودکش، شمارنده و نمودار
  • One carried object and travelling transitions — whip, push, zoom, iris — instead of slide-to-slide wipesیک شیءِ حامل و گذارهای سفرکننده — ویپ، پوش، زوم، آیریس — به‌جای وایپ‌های اسلاید-به-اسلاید
  • Type that slams, slides and drops; beat-synced camera and hitsتایپی که می‌کوبد، می‌لغزد و می‌افتد؛ دوربین و ضربه‌های هم‌ضرب
  • Sound scored from the same spec: drums, bass, pads, keys, risers, impactsصدا از همان مشخصات ساخته می‌شود: درام، بیس، پد، کیبورد، رایزر، ایمپکت
  • GPU particles, shader backgrounds and filters when a film needs themذرات GPU، پس‌زمینهٔ شیدری و فیلتر، هر وقت فیلمی لازم داشته باشد
02 — KNOWLEDGE

It knows what is possible — and whenمی‌داند چه ممکن است — و کِی

An atlas of 256 recipes with runnable code, a gallery so the agent can see before it chooses, and a generator that returns three different directions for every brief.اطلسی از ۲۵۶ دستورکار با کد اجرایی، گالری تا ایجنت قبل از انتخاب ببیند، و مولدی که برای هر بریف سه جهت متفاوت می‌دهد.

  • Every recipe: use · how · avoid · pairs-withهر دستورکار: کاربرد · روش · پرهیز · ترکیب
  • 22 complete style systems — commit to one۲۲ سیستم سبک کامل — یکی را انتخاب کن و پایش بمان
03 — PROCESS

It must use it — and prove it didباید از آن استفاده کند — و ثابت کند

Studio mode: brief → look-dev → skeleton → three polish rounds. Then gates that measure, not hope.حالت استودیو: بریف ← سبک‌یابی ← اسکلت ← سه دور صیقل. بعد دروازه‌هایی که اندازه می‌گیرند، نه امید.

  • Anti-slideshow gates: motion metric, frame-fill floor, shots of 1–2 s instead of slides, continuity (a carried object, travelling transitions)دروازه‌های ضد-اسلایدشو: معیار حرکت، کف پُری قاب، شاتِ ۱–۲ ثانیه‌ای به‌جای اسلاید، پیوستگی (شیءِ حامل، گذارهای سفرکننده)
  • Craft gate: ≥ 6 techniques, ≥ 4 transitions, 3 written reviewsدروازهٔ craft: حداقل ۶ تکنیک، ۴ ترنزیشن، ۳ بازبینی نوشته‌شده
  • Determinism proof: same time ⇒ same pixelsاثبات قطعی‌بودن: زمان یکسان ⇒ پیکسل یکسان

Don't take our word for itحرف ما را باور نکنید

  
Each agent against itself. Measured.هر ایجنت در برابر خودش. اندازه‌گیری‌شده.

  
The repository ships a benchmark: it hands a coding agent the same task in a clean folder, with and without the skill, then measures every finished film. The numbers below come straight from the committed result files — no hand-typing.ریپو یک بنچمارک دارد: همان تسک را در پوشهٔ تمیز، با و بدون اسکیل، به ایجنت می‌دهد و هر فیلم را می‌سنجد. اعداد زیر مستقیم از فایل‌های نتیجهٔ ثبت‌شده می‌آیند — بدون تایپ دستی.

  

  
frame fill = share of each frame that is not background (higher = bolder pictures) · static = share of the film where almost nothing changes (lower = more motion) · LRA = loudness range, dynamics of the mix. These measure motion and sound hygiene, not beauty — that is what the films above are for. n = 1 per cell: one run is an anecdote. Full report & method · run it yourself — and tell us if it contradicts us.پُری قاب = سهمی از هر فریم که پس‌زمینه نیست (بیشتر = تصویر جسورتر) · ساکن = سهمی از فیلم که تقریباً هیچ چیز تغییر نمی‌کند (کمتر = حرکت بیشتر) · LRA = دامنهٔ بلندی صدا، پویایی میکس. این‌ها سلامت حرکت و صدا را می‌سنجند نه زیبایی — برای زیبایی فیلم‌های بالا هست. یک اجرا برای هر خانه فقط یک حکایت است. گزارش کامل و روش · خودتان اجرا کنید — و اگر خلافش درآمد بگویید.
