# FAQ

### Which agents does it work with?
Any coding agent that can read a `SKILL.md`, run shell commands and (ideally) look at images: **Codex CLI/app** and **Claude Code** are the ones it is developed and tested with. Other agents that follow the open Agent Skills layout (`skills/<name>/SKILL.md`) can use it via `npx skills add`; if yours cannot load skills, paste the contents of `SKILL.md` into its instructions and point it at the folder.

### Do I need a GPU?
No. Rendering uses Chrome's WebGL; with no GPU it falls back to software rendering (slower, identical result). Hybrid-GPU laptops run on the integrated GPU by default, which is stable.

### How long does a film take?
Rendering a 20 s, 1080p, 30 fps film takes about 30 s – 3 min on a typical laptop (faster with a GPU, several times slower in Docker/software GL). Most of an agent session is *thinking, looking and reviewing* — studio mode runs three review rounds on purpose, so expect tens of minutes rather than a few.

### Is it really "no AI video model"?
Yes. Every pixel is drawn by code you can read (`video.html`), every sound is synthesised by code (`audio.mjs`). The *agent* is an AI; the *video* is not generated by a video model. That is why text is exact, edits are surgical and results are reproducible.

### What can it *not* do?
Photoreal people/animals/footage, camera-captured video, and anything needing a trained model's imagination of the real world. It excels at motion graphics, typography, product/UI films, abstract/generative art, stylised 3D, data stories and music visuals.

### Can I use my own logo, fonts, music or footage?
Logo: yes — a PNG on white becomes a keyed transparent mark with `K.keyWhite(img)`, then glows, morphs into particles, etc. Fonts: drop a `.woff2` in `fonts/` and load it with `K.loadFonts`. Music: bring a WAV and run `tools/analyze-audio.mjs` for audio-reactive envelopes, or let the synth write a score. Footage: `<video>` frames can be sampled deterministically, but this is not the skill's focus.

### Persian, Arabic and RTL?
First-class: correct shaping, RTL layout, Persian digits, word-by-word animation (never per-letter), seven Persian-capable faces including Nastaliq, Persian modes and instruments in the sound engine. Other scripts (CJK, Hebrew, Indic) render if you add a font for them; none are bundled.

### Is the Persian music "real"?
It is **synthesised** — santur, ney, tombak and daf are synthesised approximations with quarter-tone note names (`Ed4`) and Persian modes. They work well in a mix but are not recordings; for a commercial release have a musician review them.

### How do I know it helps? Show me.
`benchmark/` runs the same prompt with and without the skill and measures the result (motion, pacing, sound, process), plus a blind A/B rating page. See the [benchmark](benchmark.md) and run it on your own machine with your own agent.

### Can I add my own techniques?
Yes — that is the best way to contribute. An atlas entry is ~15 lines of Markdown plus a runnable snippet; see [CONTRIBUTING](../CONTRIBUTING.md#adding-a-technique-to-the-atlas).

### Is it safe to let an agent run this?
The scripts only open local files in a headless browser and run ffmpeg; they make no network calls. The *agent* runs with whatever permissions you give it — see [SECURITY.md](../SECURITY.md).
