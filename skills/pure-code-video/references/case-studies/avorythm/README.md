# Case study — "Avorythm: two voices, one meaning" (30 s, 16:9, Persian RTL, original score)

A complete film built with this skill from the brief *"Create a motion graphics piece about my product Avorythm … YOU decide the concept … surprise me … on-screen text in Persian, RTL … end with the name/logo … MP4 with audio"* (facts: an open-source real-time translation and AI-dubbing tool; the full brief is quoted in `brief.md`).
Read it to see what the protocol produces: a **specific concept** (the logo is two voices — violet source on the left, cyan target on the right — and direction itself is the theme), a **style bible**, a **storyboard where every row names a technique**, and the code that realises it.

| file | what to look at |
|---|---|
| `brief.md` | the process output: promise → visual verb → twist → hook/hero/last image → style bible → storyboard table (time · scene · atlas techniques · motion · transition · sound) → music idea |
| `video.html` | one page, 8 scenes on `Stage`; helpers worth copying: `makeLogo` (`K.keyWhite`), `filtered()` (2D scene → `fx.filterCanvas` VHS), `paintVideo()` (procedural footage with a `tint`), `chip()` glass chips, `push()` per-scene zoom, `drawBeams()` + `P3.toScreen()` (2D beams pinned to a 3D prism), `K.Frost` subtitle card, `Parts.Morph` words → the real logo (`Parts.image` from the keyed PNG), per-scene camera keys, global dust (`S.render(t,false)` + `DUST.draw` + `post.end(look)`) |
| `qc/review-1…3.md` | what a real fix list looks like: look-dev (3 findings with scene, cause, exact change) → Round A motion & camera (energy numbers) → Rounds B+C craft and sound. Copy the format: *looked at → ranked findings → fix → result* |
| `audio.mjs` | a score that tells the same story left→right: dull babble panned left (the foreign voice) → silence → impact at the click → bells for the four outputs → bright babble panned right (the dub) → santur on the Persian subtitle → riser + tom roll → 0.15 s of silence → burst → resolve on D major. All events come from the shared `cues` (`T.click`, `T.o1…`) |

How it was made (the iteration that matters, in order): concept & storyboard (brief.md) → first skeleton render (all 8 scenes, no errors) → look-dev fixes from full-size stills (prism blown out by bloom: raise `threshold`, not the lights; particle logo too dense: size/glow down; subtitles left-aligned out of the card: `K.words` centres on `cx`) → **round A motion** (`qc energy` showed calm seconds → per-scene camera moves, faster content, global dust: median energy ×2.5) → **round B craft** (sizes, safe margins, popup clipped by the camera zoom) → **round C sound** (events aligned to picture cues; sub-bass trimmed until `qc audio` passed) → verify (PASS) → `qc check` (0 warnings).
Assets: the film uses the real logo (`assets/avorythm-logo.png` from the project's repository) — not included here; replace `makeLogo` with your own mark or draw it procedurally.
